# 📱 AT SMM PANEL - Mini App (Vercel Deployment)

এই ফোল্ডারের ফাইলগুলো দিয়ে আপনি খুব সহজেই **Vercel**-এ সম্পূর্ণ ফ্রিতে টেলিগ্রাম মিনি অ্যাপ ডিপলয় করতে পারবেন।

---

## 📁 প্রয়োজনীয় ফাইলসমূহ:
1. `index.html` - মূল মিনি অ্যাপ ফ্রন্টএন্ড কোড (ভিডিওর মতো ১০০% আধুনিক ডিজাইন)
2. `config.js` - আপনার ব্যাকএন্ড / রেনডার API URL কনফিগারেশন ফাইল
3. `vercel.json` - Vercel রাউটিং ও CORS কনফিগারেশন
4. `.gitignore` - গিট ইগনোর ফাইল

---

## 🚀 ধাপে ধাপে গিটহাব এবং Vercel-এ ডিপলয় করার নিয়ম:

### ধাপ ১: GitHub-এ নতুন রিপোজিটরি তৈরি করুন
1. [github.com](https://github.com)-এ যান এবং লগইন করুন।
2. **"New repository"**-তে ক্লিক করুন।
3. রিপোজিটরির নাম দিন, যেমন: `smm-mini-app`
4. **Public** বা **Private** সিলেক্ট করে **"Create repository"** বাটনে ক্লিক করুন।
5. এই ফোল্ডারের (`mini_app_vercel`) ভেতরের সব ফাইলগুলো (`index.html`, `config.js`, `vercel.json`, ইত্যাদি) আপনার ওই গিটহাব রিপোজিটরিতে আপলোড/পুশ করুন।

---

### ধাপ ২: Render-এর ব্যাকএন্ড URL `config.js`-এ সেট করুন
1. আপনার বটের রেনডার সার্ভিস থেকে প্রাপ্ত লাইভ লিঙ্কটি নিন (যেমন: `https://your-smm-bot.onrender.com`)।
2. `config.js` ফাইলটি ওপেন করে আপনার রেনডার লিংকটি বসিয়ে দিন:
```javascript
window.BACKEND_API_URL = "https://your-smm-bot.onrender.com";
```
*(অথবা `vercel.json` ফাইলের `destination`-এ আপনার রেনডার লিংকটি বসিয়ে দিতে পারেন)*

---

### ধাপ ৩: Vercel-এ ১-ক্লিকে ডিপলয় করুন
1. [vercel.com](https://vercel.com)-এ যান এবং GitHub অ্যাকাউন্ট দিয়ে লগইন করুন।
2. **"Add New..."** -> **"Project"**-এ ক্লিক করুন।
3. আপনার গিটহাবের `smm-mini-app` রিপোজিটরিটি সিলেক্ট করে **"Import"** করুন।
4. Framework Preset হিসেবে **"Other"** থাকবে। কোনো সেটিংস পরিবর্তন করার দরকার নেই।
5. সরাসরি **"Deploy"** বাটনে ক্লিক করুন!
6. মাত্র ২০-৩০ সেকেন্ডের মধ্যে আপনার মিনি অ্যাপ লাইভ হয়ে যাবে এবং একটি লিংক পাবেন (যেমন: `https://smm-mini-app.vercel.app`)।

---

### ধাপ ৪: টেলিগ্রাম বটে মিনি অ্যাপ লিংক যুক্ত করুন
1. টেলিগ্রামে [@BotFather](https://t.me/BotFather)-এ যান।
2. `/mybots` লিখে আপনার বটটি সিলেক্ট করুন।
3. **Bot Settings** -> **Menu Button** -> **Configure menu button**-এ ক্লিক করুন।
4. আপনার Vercel-এর লাইভ লিংকটি (যেমন: `https://smm-mini-app.vercel.app`) পেস্ট করে দিন।
5. এখন যেকেউ টেলিগ্রামে বটের নিচে থাকা **"Menu"** বাটনে বা ইনলাইন বাটনে চাপলেই সরাসরি আপনার মিনি অ্যাপটি ওপেন হবে!
